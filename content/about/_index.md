Rocky Branches is a scientific consultancy. We help research and industry teams with scientific computing, geospatial analysis, infrastructure automation, developer tooling, and AI and data pipelines.

We build and maintain open source tools in the same five areas we consult in:
- Scientific computing: algorithms, simulation, and performance work
- Geospatial analysis: GIS, spatial data, and road network modeling
- Infrastructure automation: cloud and on-premise clusters, and resource monitoring
- Developer tooling: command-line tools and automation
- AI and data pipelines: data processing and analytics

Our work spans the full stack, from low-level C++ and embedded tooling to Python-based data pipelines, Kubernetes orchestration, and NixOS infrastructure.
